# Gongkao · 公考学习

一个面向公务员考试「行政职业能力测验（行测）」的本地学习程序。

项目希望提供一个简单、稳定、可以长期使用的刷题环境：

> 打开就是学习，而不是管理学习。

目前项目处于持续开发与完善阶段，核心学习流程已经可以在本地运行。

---

## ✨ 项目简介

Gongkao 是一个本地运行的个人公考学习程序。

目前主要覆盖行测五大模块：

- 常识判断
- 言语理解与表达
- 数量关系
- 判断推理
- 资料分析

当前暂不包含申论。

项目强调「学习本身」，尽量减少复杂的学习管理功能，让用户可以快速进入训练、完成题目、查看结果并回顾自己的学习记录。

---

## 📚 当前功能

目前已经实现的核心能力包括：

- 正式训练
- 专项训练
- 行测五大模块练习
- 答题与结果反馈
- 错题记录与回顾
- 学习状态查看
- 训练历史
- 本地题库
- 本地学习数据保存

项目仍在继续完善，实际功能以当前版本为准。

---

## 🧠 项目理念

这个项目不是一个复杂的「学习管理系统」。

它更希望成为一个真正用于每天学习的工具。

核心原则：

**打开 → 做题 → 反馈 → 回顾 → 继续学习**

因此当前版本不会刻意加入大量复杂功能，例如：

- 云同步
- 网络账号体系
- 社交功能
- AI 自动诊断
- AI 推荐算法
- 掌握度 / 能力模型

这些功能只有在未来确实有必要时才会考虑。

请先安装：

- Node.js 20 或兼容版本
- npm
- Git（使用 Git 克隆仓库时需要）

推荐使用 Windows 10 / Windows 11。

## 方法一：让 AI Agent 帮你安装

如果你正在使用支持 GitHub 和终端操作的 AI Agent，可以直接把本仓库地址发给它，并告诉它：

> 请克隆这个项目，阅读 README，安装依赖、构建项目并在本地启动。不要修改项目功能代码。

Agent 可以根据下面的标准安装流程完成部署。

---

## 方法二：手动安装

### 1. 克隆项目

```bash
git clone https://github.com/sunshineasy/gongkao.git
cd gongkao
```

也可以直接在 GitHub 下载 ZIP，然后解压。

### 2. 安装依赖

```bash
npm install
```

如果希望严格按照仓库锁定的依赖版本安装，也可以使用：

```bash
npm ci
```

### 3. 构建

```bash
npm run build
```

### 4. 启动

```bash
npm start
```

启动成功后，在浏览器访问：

```text
http://localhost:3000
```

# 🪟 Windows 快速启动

仓库根目录提供：

```text
启动公考.bat
```

首次使用仍需要先安装项目依赖：

```bash
npm install
```

之后可以直接双击：

**启动公考.bat**

脚本会自动：

1. 检查 Node.js / npm
2. 构建 Gongkao
3. 启动本地服务
4. 打开浏览器进入程序

默认地址：

```text
http://localhost:3000
```

> 如果 3000 端口已经存在 Gongkao 服务，启动脚本会提示先关闭已有服务。

# 💾 数据设计

Gongkao 采用本地数据优先的设计。

题库与用户学习数据相互独立，使用独立的 SQLite 数据文件。

用户学习记录通过题目的外部 ID 与题库建立关联，从而尽量降低题库数据和个人学习记录之间的耦合。

题库采用项目定义的：

**Frozen Question Bank Exchange Format V1.0**

这一设计使题库导入、验证以及用户学习数据能够保持相对清晰的边界。
